# Correctness-checkpoint size comparison

Comparison: `e94bbc6218e40771a9226fd1de202f1516e394ab` to the production sources
at `6d940b1e43ba5bbb9d3592bbea186ec9b136899e`. The working tree adds measurement
tooling, build-manifest identity and documentation, but does not change `src/`.
Both compilers use the same current corpus and the same installed Puya 5.10.1
backend. JSON reports record complete compiler, input and backend identities.

storage modes. Chainwide uses EVM ABI for its four tracked inputs, with slot
storage for Eul. These are fixed size-measurement profiles, not each fixture's
individual semantic-test configuration. `ERR` rows include profile-specific
rejections and negative inputs, and are not a semantic-suite failure count.

## Checkpoint deltas

Recovery from a compilation failure is reported separately, not as size growth.

Named mode has 33 growing and six shrinking programs, with no compile
regressions or removed programs. `memory_layout_correctness.sol` changes from
rejection to successful compilation of two programs. The largest individual
increase is `BlobParamWriteback`: 1,112 to 1,351 bytes (+239). Clear programs
are unchanged. Details: [named comparison](6d940b1e43-regression.json).

Slot mode has 74 growing and six shrinking programs, with no compile regressions
or removed programs. Seven sources recover from rejection, producing 11 programs:
`memory_layout_correctness.sol`, `rev_2_array_conversion_loop.sol`,
`rev_2_lazy_fixed_boxes.sol`, `rev_2_lazy_pages.sol`, `rev_2_lazy_struct_box.sol`,
`soltypes_array_loop.sol` and `storage_codec_correctness.sol`. Clear programs are
unchanged. Details: [slot comparison](6d940b1e43-regression-slot.json).

Chainwide changes only Eul (+11 bytes) and PolygonEcosystemToken (+8 bytes).
All eight programs compile on both sides, with no status changes or clear-program
changes. Details: [chainwide comparison](6d940b1e43-chainwide.json).

The [DCE guard note](dce-guard.md) explains the semantic boundary and its focused
measurement: **30 bytes overall across six guards**, not 30 bytes per use.
Each guard is five bytes in that fixture; that is not a universal per-use size.
